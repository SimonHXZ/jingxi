# 站

本机版。纯静态 HTML + 一个 CSS，没有脚本、没有外部字体、没有统计。

## 怎么看

双击 `index.html` 就行，不用服务器。

## 目录

```
站/
├── index.html              首页
├── style.css               全部样式
├── posts/                  每篇一个文件
│   └── thinking-01.html
└── README.md               这个文件
```

图片以后放 `img/`，用相对路径引用。

## 加一篇

1. 复制 `posts/thinking-01.html`，改名（比如 `posts/thinking-02.html`）。
2. 改标题、`<title>`、`.meta` 里的系列和日期。
3. 正文用 `<p>`，小标题用 `<h2>`。
4. 末尾的 `<section class="revisions">` 不许删——它是这个站的规矩：每篇留着改过的痕迹。
5. 回 `index.html`，在「最近」那个 `<ul class="posts">` 里加一条，指到新文件。

## 三条规矩

1. **修订记录不删。** 改了什么都记在篇末，写清哪天、改了什么、为什么。
2. **不放外链当论据。** 需要来源就写清「谁测的、哪一年」，链接另放。
3. **没有统计，也没有评论区。** 不知道谁看过、看了多久，这个站不收集。

## 以后要挪到服务器上

整个文件夹拷过去就能跑，不需要任何解释器。要挂在自己的域名下，改 `index.html` 里的相对链接即可（现在都是相对路径，不用改）。
